# Task Management API

REST API developed with C# and ASP.NET Core as a practical Software Engineering project.

## About the Project

This project focuses on backend development, REST API design, and software engineering best practices.

The application is being developed incrementally, with new features added throughout the learning process.

## Technologies

- C#
- ASP.NET Core
- .NET 10
- Git & GitHub
- Visual Studio Code

## Implemented Features

- GET /api/tasks — Retrieve sample tasks
- JSON responses
- ASP.NET Core controller-based architecture

Currently, task data is defined in memory for demonstration purposes.

## Getting Started

### Requirements

- .NET 10 SDK
- Git

### Clone the Repository

bash
git clone https://github.com/kevylinmirandaaa/task-management-api.git


### Run the Application

bash
cd task-management-api
dotnet run --project TaskManagement.Api


### Test the API

With the application running, access:

text
http://localhost:5255/api/tasks


The port may vary depending on your local configuration.
